**Goal:** F3 — встроенный просмотрщик (текст с переносом и без, hex,
поиск), F4 — `$EDITOR` (иначе `nano`), мышь, конфиг
`~/.config/terminal-commander/config.json` с сохранением при выходе и по
Options → Save setup.

**Spec:** `docs/superpowers/specs/2026-09-28-terminal-commander-design.md`
(разделы «Просмотрщик F3», «F4 Редактор», «Мышь», «Конфигурация», этап 6).

## Global Constraints

- `fs`, `ops`, `shell`, `config` не импортируют `tcell`; `ui` не импортирует `panel`, `fs`, `ops`, `shell`, `app`, `viewer`; `viewer` может импортировать `ui` и `term`; только `app` знает обо всём.
- Коммиты — Conventional Commits на английском, без `Co-Authored-By` и пометок «Generated with Claude Code».
- Ветка `feature/stage-6`, в `main` — только через PR.

## Решения

**Конфиг (`internal/config`)**
- JSON: `{"left": {"path", "mode", "sort"}, "right": {…}, "showHidden", "history": [...]}`; режим — `"brief"`/`"full"`, сортировка — `"name"`/`"extension"`/`"time"`/`"size"`/`"unsorted"` (строки, чтобы файл читался глазами; неизвестное значение — по умолчанию).
- `Load` не возвращает ошибку: нет файла или он битый — значения по умолчанию.
- `Save` пишет во временный файл рядом и переименовывает (не оставит полуфайл), права `0600` — там история команд, как у `~/.zsh_history`.
- Запуск: `tc <путь>` — левая панель в `<путь>`, правая — из конфига; `tc` без аргумента — обе из конфига; пустой путь в конфиге (первый запуск) — текущий каталог. Сохранённого каталога больше нет — как раньше: ошибка в диалоге и домашний каталог.
- Сохранение: F10 → Yes и Options → Save setup. Ошибка при выходе — красный диалог, после OK программа всё равно выходит.

**Просмотрщик (`internal/viewer`)**
- Файл не читается целиком: каждая отрисовка читает только видимые строки через `ReadAt`; положение — байтовое смещение первой строки.
- Строка — до `\n`; строка длиннее 4096 байт режется на куски по 4096 (иначе минифицированный файл в 100 МБ читался бы целиком). Поиск начала строки назад ограничен 1 МБ.
- Текст: UTF-8, невалидные байты и управляющие символы — `·`, табуляция до 8, `\r` перед `\n` не показывается. Без переноса ← → сдвигают текст по горизонтали; с переносом (F2) строка режется по ширине экрана.
- Hex (F4): `00000000  xx xx … xx  xx … xx  ascii` — 16 байт в строке.
- Верхняя строка: путь слева, справа `<размер> bytes  <процент>%` (процент — до конца видимой части); нижняя — `1 2Wrap/Unwrap 3 4Hex/Text 5 6 7Search 8 9 10Quit`.
- Поиск F7: диалог, подстрока без учёта регистра (в том числе кириллица), от начала экрана; найденное — первой строкой экрана, подсвечено. Повтор — Shift-F7 (и F19), `n` (и `т` — `n` в русской раскладке). Не нашлось — диалог «String not found». Поиск синхронный.
- Esc, F10, F3 — закрыть. F3 на каталоге и `..` — ничего; не обычный файл (FIFO, устройство) — ошибка «not a regular file», иначе `open` зависнет на FIFO.

**Редактор F4**
- Команда `$EDITOR <имя>` (иначе `nano`) через `$SHELL -c` в каталоге панели, между `Suspend` и `Resume`; `$EDITOR` может содержать аргументы (`code -w`). Если редактор завершился с ошибкой (нет такой команды) — «Press any key», чтобы было видно сообщение. После — перечитать панели. F4 на каталоге — ничего.
- `shell.Console.Run` теперь возвращает ошибку команды.

**Мышь**
- `screen.EnableMouse(tcell.MouseButtonEvents)` — только кнопки и колесо, без движения. Выделять текст в терминале — с Option (iTerm2, Terminal.app) или Shift.
- `ui.Mouse{X, Y, Action}` — Click, DoubleClick, WheelUp, WheelDown; `ui.Clicker` превращает события tcell в действия: клик — нажатие левой кнопки; двойной — второй клик в ту же клетку за 400 мс.
- Нет окон: клик по панели — сделать её активной и поставить курсор; двойной клик по файлу — действие Enter для файла (командная строка не выполняется); колесо — курсор панели под указателем на 1; клик по строке клавиш — F-клавиша.
- Окна: `ui.MouseView` — необязательный интерфейс. Dialog — клик по кнопке; MenuBar — клик по заголовку открывает меню, по пункту — выполняет, вне меню — закрывает; Progress — клик по Cancel; Viewer — колесо и строка клавиш. Остальные окна мышь не получают.

## Review Focus

1. **Огромный файл / одна строка в сотни МБ** в F3 открывается сразу, End и ↑ работают без чтения всего файла. Тесты: длинная строка без `\n`, End на большом `bytes.Reader`.
2. **F3 на FIFO** не вешает `tc`. Тест: `mkfifo` + F3 → диалог ошибки.
3. **Битый или чужой конфиг** (не JSON, неизвестный режим, пустой файл) — запуск со значениями по умолчанию. Тест `TestLoadBroken`.
4. **Поиск кириллицы без учёта регистра** и совпадение на границе блоков чтения. Тесты `TestFindFold`, `TestFindAcrossChunks`.
5. **Двойной клик** не срабатывает от двух кликов в разных местах или с большой паузой; колесо не меняет активную панель. Тесты `TestClicker`, `TestWheelScrollsPanelUnderPointer`.
