# Terminal Commander — дизайн v1

Дата: 2026-09-28

## Цель

Терминальный двухпанельный файловый менеджер для macOS, внешне максимально
близкий к Norton Commander 4/5 (DOS), и при этом пригодный для ежедневной
работы. Проект одновременно ностальгический (важно точное сходство с NC)
и практический (важны скорость и надёжность).

Референсы: скриншоты NC 5 — две синие панели с двойными бирюзовыми рамками,
краткий режим в 3 колонки, выпадающее меню F9 с тенью, серый диалог
«Drive Letter» с кнопками и чёрной тенью, чёрная командная строка,
строка F-клавиш «цифра на чёрном + подпись на бирюзовом».

## Целевая среда

- macOS (Apple Silicon), Go 1.27.
- Терминалы: iTerm2, встроенные терминалы VS Code и JetBrains, Orca, Terminal.app.
- F-клавиши у пользователя работают как F-клавиши (без Fn).

## Технологии

- Go + `github.com/gdamore/tcell/v2` — прямая отрисовка по ячейкам.
- `github.com/mattn/go-runewidth` — ширина символов (эмодзи, CJK).
- Никаких UI-фреймворков (tview, Bubble Tea): свой тонкий слой отрисовки.
- Бинарник: `tc`.

### Режим `tc --keytest`

Диагностика клавиш: вместо интерфейса показывает на экране каждое
распознанное событие (имя клавиши tcell, модификаторы, руна, а также
результат нормализации Esc-префикса). Выход — `Control-C`. Нужен, чтобы
проверить в каждом терминале, доходят ли Option-F1, Shift-F8, Control-1
и т. п.

## Архитектура

```
cmd/tc/main.go   точка входа: инициализация экрана, главный цикл, recover
internal/
  term/    палитра EGA, выбор true color / 256 цветов, примитивы
           (текст, двойная/одинарная рамка, заливка, тень)
  ui/      интерфейс View { Draw(canvas); HandleKey(ev) bool },
           стек модальных окон, виджеты: поле ввода, кнопка, список
  panel/   файловая панель: путь, записи, курсор, прокрутка, выделение,
           режим (краткий/полный), сортировка; отрисовка панели
  fs/      чтение каталогов, список «дисков» (/, ~, /Volumes/*),
           форматирование размеров, дат и времени в стиле NC
  ops/     copy / move / delete (trash и permanent) / mkdir; работают
           в горутине, шлют события прогресса и запросы решений
           (конфликт, ошибка), не зависят от UI
  viewer/  просмотрщик F3: текст (с переносом/без), hex, поиск
  shell/   командная строка: редактирование, история, запуск через zsh,
           Control-O
  config/  загрузка/сохранение ~/.config/terminal-commander/config.json
  app/     склейка: две панели, меню F9, строка клавиш, командная строка,
           раскладка, маршрутизация клавиш, действия
```

Правила границ:
- `fs`, `ops`, `config` не импортируют `tcell` и ничего не знают об экране.
- `panel` не знает о другой панели, меню и командной строке.
- Только `app` знает обо всём.

### Поток событий

1. Главный цикл получает событие tcell (клавиша, мышь, resize, событие
   прогресса операции через `PostEvent`).
2. Клавиатурное событие проходит через нормализатор клавиш (Esc-префикс).
3. Если стек модальных окон не пуст — событие получает верхнее окно.
   Иначе — `app`, который отображает клавишу в действие.
4. После обработки экран перерисовывается целиком (tcell отправляет
   в терминал только изменения).

### Esc-префикс

`Esc` обрабатывается сразу (закрыть диалог / очистить командную строку)
и одновременно на 1 секунду «взводит» префикс. Если следующая клавиша
пришла в течение секунды, к ней добавляется модификатор Alt (Option).
Исключение: если `Esc` закрыл модальное окно, префикс не взводится —
иначе `Esc` `9` в меню закрывал бы его и тут же открывал снова.
Примеры:
- `Esc` `.` = Alt-. → переключить скрытые файлы;
- `Esc` `F1` / `F2` = Alt-F1 / Alt-F2 → выбор диска левой/правой панели;
  в общем случае `Esc` + F-клавиша = Alt (Option) + F-клавиша.

Затем Alt + цифра `1`…`9`, `0` превращается в F1…F10 (так что
`Esc` `5` = Alt-5 = F5). Tcell может сам склеить быстро нажатые `Esc`
и клавишу в Alt-клавишу — результат тот же.

### Внешние программы

Запуск команд командной строки и `$EDITOR` выполняется при
`screen.Suspend()`; после завершения — `screen.Resume()` и перечитывание
обеих панелей.

## Внешний вид

### Раскладка

- Минимальный размер 80×24; меньше — сообщение «Window too small».
- Строки `0 … H-3`: две панели по половине ширины (при нечётной ширине
  лишняя колонка у правой).
- Строка `H-2`: командная строка — приглашение `<путь активной панели>>`
  (домашний каталог сокращается до `~`), светло-серый на чёрном.
- Строка `H-1`: строка клавиш
  `1Help 2Menu 3View 4Edit 5Copy 6RenMov 7Mkdir 8Delete 9PullDn 10Quit`
  равномерно по ширине; цифра светло-серая на чёрном, подпись чёрная
  на бирюзовом.
- Полоса меню (`Left  Files  Commands  Options  Right`) появляется
  в строке 0 поверх верхних рамок только при F9.
- Resize обрабатывается: раскладка пересчитывается, курсор панели
  остаётся в видимой области.

### Палитра (EGA)

| Имя | RGB |
|---|---|
| black | `#000000` |
| blue | `#0000AA` |
| cyan | `#00AAAA` |
| red | `#AA0000` |
| lightgray | `#AAAAAA` |
| brightcyan | `#55FFFF` |
| yellow | `#FFFF55` |
| white | `#FFFFFF` |

Если `COLORTERM` равен `truecolor` или `24bit` — цвета задаются RGB.
Иначе используются ближайшие цвета 256-цветной палитры xterm.

### Цветовые роли

| Элемент | Текст / фон |
|---|---|
| Фон панели, имена файлов, рамка | brightcyan / blue |
| Заголовки колонок | yellow / blue |
| Курсор | black / cyan |
| Выделенные файлы | yellow / blue (под курсором: yellow / cyan) |
| Путь в рамке активной панели | black / cyan |
| Путь в рамке неактивной панели | brightcyan / blue |
| Меню и выпадающие списки | black / cyan; выбранный пункт white / black |
| Диалог | black / lightgray, двойная рамка white, заголовок в разрыве рамки |
| Кнопка / кнопка в фокусе | black / white; black / yellow |
| Диалог ошибки / Shift-F8 | white / red |
| Тень окон | black, смещение: +2 колонки вправо, +1 строка вниз |
| Командная строка | lightgray / black |

### Панель

- Двойная рамка `╔═╗ ║ ╚═╝`, разделитель над мини-статусом `╟─╢`,
  вертикальные разделители колонок `│` с соединителями `╤`/`╧`.
- Путь по центру верхней рамки (обрезается слева с `…`, если длинный).
- Заголовки колонок жёлтые по центру колонки.
- Мини-статус (одна строка над нижней рамкой):
  - без выделения: имя, размер (или `►SUB-DIR◄` / `►UP--DIR◄`), дата
    `M-DD-YY`, время `h:mma`/`h:mmp`;
  - с выделением: `N bytes in M selected files` (N с разделителями тысяч).

**Краткий режим** — 3 колонки `Name` равной ширины. Для файлов
с расширением длиной 1–3 символа — как в DOS: имя слева, расширение
в 3-символьном поле у правого края колонки, прижатое к началу поля
(`autoexec  bat`, `read      me`). Остальные имена выводятся
целиком. Если имя не помещается, оно обрезается, и последний видимый
символ заменяется на `}`. Курсор ←/→ переходит между колонками.

**Полный режим** — колонки `Name | Size | Date | Time`. Размер
выровнен вправо; для папок `►SUB-DIR◄`, для `..` — `►UP--DIR◄`.

Переключение режимов: пункты «Brief» / «Full» меню Left/Right,
Control-T — переключить режим активной панели (Brief ↔ Full),
а также Control-1 / Control-2 (большинство терминалов их не передаёт,
см. `docs/terminal-compat.md`).

**Сортировка**: `..` первой, затем папки, затем файлы; внутри групп —
по имени без учёта регистра. Меню Left/Right предлагает: Name, Extension,
Time, Size, Unsorted.

**Скрытые файлы** (имя начинается с `.`, кроме `..`): по умолчанию скрыты.
Переключаются: `Alt-.`, `Esc` затем `.`, пункт Options → «Show hidden files».
Настройка общая для обеих панелей и сохраняется в конфиге.

**Символические ссылки**: отображаются как файл или папка по цели;
битые ссылки — как файлы. Вход в ссылку на папку разрешён.

## Поведение

### Клавиши

| Клавиша | Действие |
|---|---|
| ↑ ↓ ← → | перемещение курсора (←/→ — между колонками в кратком режиме, в полном — PgUp/PgDn) |
| Home / End (Fn-← / Fn-→) | в начало / конец списка |
| PgUp / PgDn (Fn-↑ / Fn-↓) | на страницу |
| Enter | если командная строка не пуста — выполнить её; иначе: папка — войти, `..` — вверх, исполняемый файл — запустить, остальное — открыть через `open` |
| Backspace при пустой командной строке | на уровень выше |
| Control-PgUp | на уровень выше |
| Tab | переключить активную панель |
| Insert, Space (при пустой командной строке) | выделить/снять выделение и шаг вниз |
| `+` / `-` / `*` (при пустой командной строке) | выделить по маске / снять по маске / инвертировать |
| Alt-буква | быстрый поиск по имени: курсор на первое имя, начинающееся с набранного (без учёта регистра); поле — в строке состояния панели; дальше буквы набираются без Alt, буква без совпадения не добавляется, Backspace стирает; Esc завершает, Enter/стрелки/другие клавиши завершают и срабатывают как обычно |
| F1 | справка (окно со списком клавиш) |
| F2 | открыть полосу меню (как F9); пользовательское меню NC — вне рамок v1 |
| F3 | просмотр |
| F4 | редактирование в `$EDITOR` (иначе `nano`) |
| F5 | копировать |
| F6 | переименовать/переместить |
| F7 | создать папку |
| F8 | удалить в Корзину |
| Shift-F8 | удалить навсегда |
| F9 | меню |
| F10 | выход (с подтверждением) |
| Option-F1 / Option-F2 (Alt), Esc F1 / Esc F2 | выбор «диска» левой / правой панели |
| Alt-. , Esc `.` | скрытые файлы вкл/выкл |
| Control-O | спрятать/показать панели |
| Control-R | перечитать активную панель |
| Control-T | краткий ↔ полный режим активной панели |
| Control-U | поменять панели местами |
| Control-Enter | вставить имя под курсором в командную строку |
| Control-E / Control-X | предыдущая / следующая команда из истории |
| Esc 1…0 | F1…F10 |

Если командная строка не пуста, печатные символы (включая Space
и `+ - *`) и Backspace идут в командную строку. Стрелки всегда
управляют панелью.

### Выбор «диска»

Диалог в стиле «Drive Letter» по центру над соответствующей панелью:
кнопки `/`, `~` и по одной на каждый том в `/Volumes` (кроме ссылки
на загрузочный том). ←/→ — выбор, Enter — перейти, Esc — отмена.
Кнопки подписываются именем тома (обрезается до 12 символов).

### Меню F9

- **Left / Right**: Brief, Full, ─, Name, Extension, Time, Size, Unsorted,
  ─, Re-read, Drive…
- **Files**: Help F1, View F3, Edit F4, Copy F5, Rename/Move F6,
  Make directory F7, Delete F8, Delete permanently Shift-F8, ─,
  Select group +, Unselect group -, Invert selection *, ─, Quit F10
- **Commands**: Swap panels Control-U, Panels on/off Control-O,
  Command history
- **Options**: Show hidden files Alt-., Human-readable sizes, Save setup

Навигация стрелками, Enter — выполнить, Esc — закрыть, горячие клавиши
справа от пунктов. Клик мышью по полосе меню и пунктам работает.

### Операции с файлами

Источник: выделенные файлы активной панели, если их нет — файл под
курсором (`..` не участвует). Назначение по умолчанию — путь другой панели.

**F5 Copy / F6 RenMov** — диалог «Copy N files to:» / «Rename or move N
files to:» с редактируемым полем пути, кнопки Copy/Move и Cancel.
- Если назначение — существующая папка, файлы кладутся внутрь; иначе
  (один источник) — это новое имя.
- Копирование рекурсивное; сохраняются права и время изменения;
  симлинки копируются как ссылки.
- Конфликт имён: диалог Overwrite / Skip / Overwrite all / Skip all /
  Cancel.
- Запрещено копировать/перемещать папку внутрь неё самой (ошибка).
- F6: при одном томе — `os.Rename`; при `EXDEV` — копирование и удаление
  источника после успешного копирования.

**F7 Mkdir** — диалог с полем имени; `os.MkdirAll`; после создания
курсор ставится на новую папку.

**F8 Delete** — подтверждение «Move N files to Trash?», выполняется
через `/usr/bin/trash` (поддерживает «Вернуть» в Finder).

**Shift-F8** — красный диалог «Delete N files permanently?»; для непустых
папок дополнительно «Directory X is not empty. Delete it?» с вариантами
Delete / All / Skip / Cancel. `os.RemoveAll`.

**Прогресс**: для операций дольше ~300 мс — окно с именем текущего файла,
полосой прогресса текущего файла и общей (по байтам), кнопкой Cancel
(Esc или C; Enter не отменяет, чтобы зажатый после подтверждения Enter
не прервал операцию).
Операция выполняется в горутине; отмена проверяется между файлами
и между блоками копирования (1 МиБ). При отмене недокопированный
файл удаляется.

**Ошибки** (нет прав, файл исчез, нет места): красный диалог с текстом
ошибки и кнопками Retry / Skip / Cancel. Для ошибок, которые повтор
не исправит (копирование папки в саму себя, цель уже существует), —
только Skip / Cancel. После операции обе панели
перечитываются, выделение снимается с успешно обработанных файлов.

### Командная строка

- Редактирование: печать, Backspace, Esc — очистить строку.
  Курсор всегда в конце строки: стрелки управляют панелью, как в NC.
- Enter: `cd <путь>` (включая `cd`, `cd ~`, `cd -`, `cd ..`)
  обрабатывается внутри — меняет каталог активной панели. Остальное:
  `screen.Suspend()`, печать `<prompt> <команда>`, запуск
  `$SHELL -c` (по умолчанию `/bin/zsh`) в каталоге активной панели
  с подключёнными stdin/stdout/stderr, затем «Press any key to
  continue…», `screen.Resume()`, перечитать панели.
- История: до 500 команд, без повторов подряд, сохраняется в конфиге.

### Control-O

Приостанавливает tcell (`Suspend`), показывая основной экран терминала
с выводом прошлых команд, и ждёт нажатия любой клавиши (в сыром режиме
чтения stdin), затем `Resume`.

### Просмотрщик F3

Полноэкранное окно: верхняя строка — имя файла, размер, позиция;
нижняя — строка клавиш просмотрщика (`2Wrap 4Hex 7Search 10Quit`).
- Текст: UTF-8; невалидные байты показываются как `·`; табуляция
  раскрывается до 8; перенос строк переключается F2.
- Hex: смещение, 16 байт в hex, ASCII-колонка.
- Поиск F7 (подстрока, без учёта регистра), повтор — Shift-F7 / `n`.
- Файл читается постранично через `ReadAt`, чтобы большие файлы
  открывались мгновенно.
- Esc / F10 / F3 — закрыть.

### F4 Редактор

`$EDITOR` (или `nano`) с путём файла; через Suspend/Resume;
после выхода панели перечитываются.

### Мышь

Клик выбирает панель и ставит курсор; двойной клик = Enter; колесо —
прокрутка; клик по строке клавиш = соответствующая F-клавиша; клик
по меню и кнопкам диалогов работает.

### F1 Справка

Модальное окно со списком клавиш (прокручиваемое), закрывается Esc.

### Выход

F10 — диалог «Do you want to quit Terminal Commander?» Yes / No.
При выходе сохраняется конфиг.

## Конфигурация

`~/.config/terminal-commander/config.json`:
- режим и сортировка каждой панели;
- показ скрытых файлов;
- последний каталог правой панели (при запуске она открывается там;
  левая открывается в текущем каталоге, а при `tc <путь>` — в
  `<путь>`, как в Midnight Commander);
- история команд.

Сохраняется при выходе и по пункту Options → Save setup. Отсутствующий
или битый файл — используются значения по умолчанию, ошибка не
показывается.

## Надёжность

- `recover` в главном цикле: восстановить терминал (`screen.Fini()`),
  записать стек в `~/.config/terminal-commander/crash.log`, вывести
  короткое сообщение.
- Недоступные каталоги (нет прав) — ошибка в диалоге, панель остаётся
  в прежнем каталоге.
- Если текущий каталог панели удалили извне — при перечитывании панель
  поднимается к ближайшему существующему родителю.

## Тестирование

- `fs`, `ops`, `config`: юнит-тесты на `t.TempDir()` — копирование
  дерева с симлинками и правами, перемещение, конфликты, отмена,
  копирование папки в саму себя, mkdir вложенных путей, удаление;
  Корзина — реальный вызов `/usr/bin/trash` на временном файле.
- `panel`: сортировка, курсор и прокрутка, выделение по маске, выход
  наверх с позиционированием курсора, обрезка имён `}`, форматирование.
- Отрисовка: golden-тесты на `tcell.SimulationScreen` 80×25 — панели
  в обоих режимах, меню, диалог, строка клавиш; эталоны в
  `testdata/*.golden` (символы и роли цветов), обновление флагом
  `-update`.
- Клавиши: симулированные события (Esc+5 → Copy, Backspace при пустой
  строке → вверх, Alt-. → скрытые файлы).
- Ручная проверка: iTerm2, VS Code, JetBrains, Orca, Terminal.app.

## Сборка

- `go build -o tc ./cmd/tc`.
- `Makefile`: `build`, `test`, `install` (копирует в `~/bin`).

## Этапы реализации

1. `term` + каркас `app`: экран в цветах NC, строка клавиш, F10,
   Esc-префикс, режим `--keytest`.
2. `fs` + `panel`: две панели, навигация, режимы, мини-статус, скрытые
   файлы, сортировка.
3. `ui`: диалоги, меню F9, выбор диска, справка F1.
4. `ops`: F5 / F6 / F7 / F8 / Shift-F8 с прогрессом и ошибками.
5. `shell`: командная строка, Control-O, история.
6. F3 просмотрщик, F4 редактор, мышь, `config`.

После каждого этапа программа собирается и запускается.

## Вне рамок v1

Встроенный редактор, пользовательское меню F2, поиск файлов Alt-F7,
сравнение каталогов, архивы, FTP/сетевые панели, обёртка оболочки
для смены каталога после выхода, Quick View / Tree / Info панели.
